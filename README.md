# Gita Vaani

**Voice of the Eternal Gita** — A spiritual guidance web application rooted in the wisdom of the Bhagavad Gita, available in Hinglish, Hindi, and English.

## Project Description

Gita Vaani is a modern, interactive React-based application designed to provide life guidance and spiritual wisdom from the Bhagavad Gita. The application features a clean, minimalist interface with support for multiple languages (English, Hindi, and Hinglish) to make sacred wisdom accessible to a broader audience. Users can seek guidance, save their favorite verses, and receive daily inspirations grounded in the teachings of the Gita.

## Features Implemented

### Core Features

1. **Seek Tab** - Search and discover guidance
   - Search through Bhagavad Gita verses and teachings
   - Read detailed explanations and interpretations
   - Save favorite verses for later reference
   - Beautiful card-based verse display

2. **Saved Tab** - Personal collection of favorites
   - View all saved verses and guidance
   - Quick access to your favorite teachings
   - Badge showing count of saved items
   - Remove verses from saved collection

3. **Daily Tab** - Daily spiritual inspiration
   - Receive daily verse and guidance
   - Rotating inspirational messages from the Gita
   - Encouragement for daily practice
   - Spiritual reflection prompts

### UI/UX Features

- **Multi-language Support** - Devanagari script support for Hindi
- **Responsive Design** - Optimized for mobile and desktop
- **Sticky Header** - Navigation stays accessible while scrolling
- **Tab Navigation** - Three main sections with clear icons and labels
- **Saved Items Badge** - Visual indicator of saved verses count
- **Smooth Animations** - Fade-in effects and transitions
- **Custom Scrollbar** - Themed scrollbar matching design
- **Backdrop Blur** - Modern glass-morphism effects

### Design Elements

- Saffron color theme (traditional Indian spiritual color)
- Devanagari font support for authentic Hindi text
- Serif typography for verses and content
- Parchment background texture
- Clean, minimalist aesthetic
- Accessible color contrast
